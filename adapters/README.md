# 宿主适配约定

简体中文 | [English](README.en.md)

这里维护不同代理的加载差异。标准规则与技能仍在 rules/ 和 skills/，不为每个代理建立独立正文。当前提供适配约定和支持证据，没有自动转换器，也不保证所有客户端已实测。

## 适配顺序

1. 首先核实并优先使用 `.agents/skills/` 与 `.agent-rules/agent-rules-and-skills/`。通用技能目录已支持时，不按品牌选择专用目录；只在通用目录无法满足需要时使用专用目录，记录依据。验证原生发现与普通文件读取的区别，已有安装按授权迁移并排查遮蔽，不盲目保留两份。
2. 增加薄的项目加载入口，引用同一规则正文。AGENTS.md 是优先共享入口，不假定所有客户端、模式、版本都会读取它。
3. 只有原生格式确实要求时才转换必要元数据或调用语法，并保留完整资源。记录原字段、目标字段、理由、宿主版本和受影响能力。
4. 不能等效表达时注明能力损失，必要时停止该宿主适配；不通过删条件、缩写步骤或改触发范围使文件看似兼容。

适配方案保存在这个真源仓库，具体项目生成结果在安装记录中指向方案及版本。一次新的适配在真源尚未登记时标为临时、待汇回，不能悄悄成为该代理永久独有规则。目录位置不同但内容原样复制，也要记录目标路径及来源。

语言不是重写安装技能的理由。运行指令保持统一英文，输出遵循用户语言；宿主正式支持且已记录时可以本地化展示字段，不改变技能 ID、行为或触发条件。

## 当前证据与限制（2026-10-28）

| 宿主 | 已核对内容 | 处理 |
| --- | --- | --- |
| Codex | 项目 `.agents/skills/`，AGENTS.md 规则；此前已核对官方说明 | 优先原样技能及项目入口；见 [项目安装研究](../doc/设计/project-first-installation.md) |
| Cursor | 支持多个项目技能目录，已有官方资料依据 | 优先共用可发现目录，检查重复发现及 Rules 是否覆盖共同入口；同上 |
| Qoder CLI | 官方列项目 `.qoder/skills/`，个人同名技能优先 | 核对实际来源，不把 CLI 支持自动推广到 IDE 或新桌面产品。[CLI skills](https://docs.qoder.com/cli/Skills) |
| Qoder IDE | 官方说明 AGENTS.md 兼容，Rules 冲突时优先 | 现有 Rules 仍需检查，不能只看根文件。[IDE rules](https://docs.qoder.com/user-guide/rules) |
| Hermes | 官方技术说明列 `.hermes/skills/` 和 `.agents/skills/` 项目技能，需要项目信任，并区分自动维护策略 | 原样项目包优先，不默认改为个人副本；不擅自改变信任或管理配置。[Skills System](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills/) |
| TRAE | 官方技能页可定位，但本次抓取没有正文，规则页超时 | 路径、格式与自动触发均标待核实；安装时查当前官方文档或本地能力，不能依据其他代理推断。[官方技能入口](https://docs.trae.ai/ide/skills) |

其他代理按相同方式补证据。读取文档不是实测；不能因 SKILL.md 文件名相同就认定元数据、工具能力与调用语义完全一致。

2026-10-29 用户反馈：其 Qoder 环境也识别 `.agents/skills/`。这说明 `.qoder/skills/` 不是唯一候选；尚未记录具体版本与模式，不能推广为所有 Qoder 环境保证。安装时优先核实通用目录。
