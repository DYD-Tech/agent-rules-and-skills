# 双语分发 / Language packages

内置模块按语言存放在 rules/ 和 skills/ 的 English、中文子目录中。可直接说“用中文安装通用规则和项目仓库结构”。每个模块只安装一种语言，模块 ID 和目标加载路径保持稳定。 英文和中文都是可执行的指令。行为修改在同一次提交中更新两个版本，并核对条件、例外、资源及触发规则。

Bundled rules and skills are available in English and Chinese under the English and 中文 folders. Ask for a language when installing, for example “Install General development and Project repository structure in English.” Install one language per module using its stable ID and target path. Maintain both variants together and verify matching behavior and resources.
