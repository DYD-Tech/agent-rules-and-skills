# 开发变更记录

以下版本号标识仓库内开发修订，不代表已经发布、提交或推送。

## 未发布 — 0.4.0

- 增加英文 README、安装、同步、目录、记录格式及适配指南；规则和技能采用统一英文运行指令，中文对照放 doc/中文对照。模块保留稳定 ID 和中文别名，语言不改变安装或触发；安装排除阅读对照，并补充双语同步维护要求。历史备份不改写。

- 明确本项目跨项目、跨 agent 管理规则与技能的定位；区分直接使用与升级、拥有写权限的源仓库维护、fork 自主管理及 PR 贡献。源仓库维护流程补齐按需 clone、权限与任务授权、验证发布、再更新项目及 fork 迁移边界；不要求用户先手动 clone，也不将普通安装视为发布授权。

- 明确选定仓库或 fork 为唯一维护来源；增加比对、更新、偏离分类和汇回流程，项目约定与宿主适配分开。
- 固定清晰沟通外部模块到已通过远端 ref 核对的提交，避免每个项目分别追踪 main。
- 增加适配证据目录与安装记录 v1，补充 Qoder、Hermes 和 TRAE 的已知或未核实边界。
- 增加只读本地安装偏离检查器；8 项标准库测试通过，覆盖内容变化、缺失、额外文件、区块与路径边界。工具不检查上游最新，也不自动安装或同步。

## 开发记录 — 0.3.0（未发布）

- 安装指南明确项目优先：规则、完整技能和触发要求随项目，区分内容归属与宿主发现目录；补充多代理适配、同名版本冲突、个人执行副本授权、本地绑定和云端核验。官方文档核对已完成，新增环境组合尚未实测。

- 按用户要求整理 doc：根目录仅保留 README.md，其余文档归入调研、设计、评测和历史草案等子目录；同步文件链接，并在本仓库规则中固定该约定。

- 增加模块目录与代理安装指南：可组合规则和技能，外部模块按上游地址获取；当前登记清晰沟通模块，不复制外部源码。
- 增加开发日志规则与技能；架构—功能—实现只描述当前版本，历史与计划分别归入日志和任务记录。
- 将原开发变更记录移至本目录，更新原有链接。此举为当前用户要求的文档组织调整，不代表每次安装模块都要迁移历史文件。
- 本次验证包括清单、引用和文件边界检查，以及作者使用日志技能整理本次变化；远端安装、跨宿主默认触发与独立模型行为仍待验证。未修改全局配置或将模块安装进其他项目。
