# 功能全貌

| 用户目标 | 当前能力 | 入口 |
| --- | --- | --- |
| 挑选规则和技能 | 按中文名称、ID、别名、标签及来源浏览四个模块；代理可以按需求推荐 | [模块目录](../../catalog/README.md) |
| 让代理安装组合 | 代理按清单取得完整文件、保留现有指引、生成加载入口并记录来源；支持手动执行相同步骤 | [安装指南](../../INSTALL.md) |
| 比对和更新已安装内容 | 代理按锁定来源比较上游版本和本地结果；只读工具检测本地偏离，通用改进汇回真源 | [同步流程](../../SYNC.md) |
| 使用专业开发要求 | 通用规则约束任务、设计、标准、验证、维护和沟通 | [通用规则](../../rules/development.md) |
| 理解当前系统并积累知识 | 三层文档说明当前能力、机制及设计理由 | [文档技能说明](02-文档技能.md) |
| 追踪发生过的变化 | 独立日志记录重要变化、理由、验证和剩余问题，普通变化集中记录 | [开发日志技能](../../skills/development-log/SKILL.md) |
| 从单一入口取得外部技能 | 目录登记清晰沟通的上游仓库和路径，代理安装时获取，不复制上游源码到本仓库 | [模块清单](../../catalog/modules.json) |

这里的安装能力是一套供代理或人执行的流程，不是安装器程序。没有自动更新服务或跨客户端一致性保证；第三方条目也不代表已经完成安全审查。当前每个模块都可独立选择，可选推荐不会被自动安装。
